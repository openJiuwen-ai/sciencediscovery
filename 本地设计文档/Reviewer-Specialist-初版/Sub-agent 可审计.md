### 🚀 背景描述

来源：[ScienceAgent 0.1.0 版本特性需求计划表](https://gitcode.com/mindspore/ScienceAgent/wiki/ScienceAgent-0.1.0版本特性需求计划表.md) 编号 **6**。

- **模块**：Agent 编排
- **特性**：Sub-agent 可审计
- **优先级**：高

功能说明：

以 Reviewer Specialist 作为审计模块的统一概念描述，分别实现 `computation-reviewer` 和 `citation-reviewer`，完成以下四个功能点：

1. **计算真实性**：验证 Artifact 中计算型 Claim 对应的 Provenance 链路是否完整，确认计算经过真实执行。
2. **数据一致性**：验证 Artifact 中的计算结果与 Provenance 链路中的标准化结果是否一致。
3. **论文真实性**：验证 Artifact 中引用的论文是否真实存在，并检查 DOI 等标识符是否与论文元数据一致。
4. **论文与陈述的匹配性**：验证引用论文是否能够支持 Artifact 中归属于该论文的陈述。

其中：

- `computation-reviewer` 负责计算真实性和数据一致性审核。
- `citation-reviewer` 负责论文真实性和论文与陈述匹配性审核。
- Reviewer 仅审核已落盘、已登记且具有明确版本的 Artifact，不直接审核聊天中间输出。

本 issue 用于跟踪 0.1.0 版本该特性的设计与落地。

### 设计思路

1. 按计算真实性、数据一致性、论文真实性、论文与陈述匹配性四个功能点拆解验收标准与里程碑。
2. 复用已完成初版的 `citation-reviewer`，按初版方案实现 `computation-reviewer`，并由 Reviewer Specialist 统一承载。
3. `computation-reviewer` 与 6.2 Provenance 五维溯源功能对齐，通过 Artifact 中的图谱标记验证计算链路和结果一致性。
4. 优先保证四个功能点的可演示、可联调路径，具体技术方案在实现过程中补充设计文档与 PR 说明。

### 涉及到的对外API

前端提供两个审核操作入口：

1. **自动触发开关**：用于控制是否自动触发审核。
2. **手动执行按钮**：用于由用户主动触发审核。

自动触发的具体时机和前后端调用逻辑在设计和实现阶段进一步明确；手动执行用于增量补审截至当前尚未审核的 Artifact。

若涉及对外 API、Skill、Connector 或配置面变更，需在实现 PR 中说明兼容性与迁移方式。

### 与其他模块的相关性描述

- 所属模块：Agent 编排。
- 与 **6.2 Provenance 五维溯源**相关：使用其知识图谱和溯源信息，对计算结果、输入数据和执行产物进行数据一致性及计算真实性审核。
- 与文献检索和论文解析能力相关：用于完成论文真实性及论文与陈述匹配性审核。
- 联调与端到端验收与计划表「联调案例」及相邻特性协同验证。

### 测试设计与测试计划

1. **计算真实性**：覆盖缺少或无效 Provenance 标记、计算链路不完整及链路完整等场景。
2. **数据一致性**：覆盖 Artifact 数值与图谱标准化结果不一致、单位或范围不一致及正常一致等场景。
3. **论文真实性**：覆盖 DOI 指向其他论文、论文不存在、论文元数据不匹配及正常匹配等场景。
4. **论文与陈述匹配性**：覆盖论文不支持陈述、部分支持、与陈述矛盾及完全支持等场景。
5. **触发方式**：验证前端自动触发和手动触发两种审核方式。
6. **回归**：相关单测、集成测试与手动冒烟清单随 PR 补充结果。
