# Agent Team 科研协作

Agent Team 通过 `science-research-team` 技能组织多个分工明确的 Agent，完成文献调研、数据分析和报告。你提供问题、材料和交付要求，主 Agent 负责安排工作、传递结果并汇总交付。

它适合需要多个步骤的任务，例如分析一份数据、检查分析是否可靠，再写成报告。操作示例见[用 Agent Team 分析免疫特征](../domains/agent-team-data-analysis.md)。

## 怎样开始

确认技能库中的 `science-research-team` 在当前会话可用，然后在聊天中明确提出：

```text
请使用 science-research-team 分析我上传的数据。
先检查数据，再完成分析和结果复核，最后输出报告、图表和可复跑的代码。
```

补充你要回答的问题、数据文件及字段含义、分析范围和输出格式。所需的内置专家应已启用；文献任务需要可用的检索连接器，代码分析需要可用的执行环境。缺少必要角色或技能时，Agent 会提示补齐配置。

## 团队怎样分工

| 角色 | 负责什么 |
|---|---|
| `literature-searcher` | 查找相关文献，整理来源 |
| `evidence-extractor` | 从已找到的材料中提取证据和限制 |
| `code-engineer` | 编写、运行分析代码，保存结果与图表 |
| `result-evaluator` | 检查方法、结果和可复现性，提出修改意见 |
| `report-writer` | 根据已有结果撰写报告，保留分歧和未解决的问题 |

团队按任务需要启用角色。只有数据分析需求时，主要由分析、复核和报告三个角色完成；需要文献支持时，先完成调研，再把证据交给后续分析。

独立的文献子任务可以并行，但依赖前一步结果的工作要依次完成。例如，复核需要等分析结果出来，报告需要等结果汇总完成。

## 复核后怎样处理

复核通过后，团队进入报告阶段。需要修改时，分析 Agent 按复核意见重做，再交给复核 Agent 检查。

技能默认最多进行 3 轮分析与复核。如果达到上限仍未通过，会保留最新结果并标明分析尚未完成，说明待解决的问题。看到文件已经生成，并不代表它通过了复核。

这套流程由技能指导 Agent 执行，实际完成情况需要结合任务记录和产物确认。

## 最后能得到什么

可以在任务中指定报告语言、文件名和格式，以及是否需要图表、数据表、代码和运行说明。最终交付应说明完成了哪些工作、复核是否通过，以及还有哪些限制。

阅读结果时，重点检查结论能否对应到数据或文献，方法是否有记录，未完成部分是否明确。复核能帮助发现问题，但不能保证每个结论都正确。

如果你的重点是提出并反复改进研究方案，可以使用 [Idea Tree](idea-tree.md)；Agent Team 更适合围绕已有问题和材料完成调研、分析与交付。
