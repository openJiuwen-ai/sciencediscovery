# Idea Tree 研究方案探索

Idea Tree 帮你围绕一个研究目标提出多个方案，分别评估，再根据发现的问题继续改进。它把研究方向、候选方案和评估意见保存在一棵树中，方便你比较：哪些方向值得继续，哪些问题还需要验证。

适合这样的任务：“我想设计一种降解水中污染物的催化剂，有哪些路线值得尝试？”完整操作见[用 Idea Tree 探索水处理催化剂](../domains/idea-tree-catalyst-design.md)。

## 怎样开始

在会话中输入 `/idea-tree`，后面写研究目标、约束和已有材料。`/idea-tree-team` 也是同一功能的入口。

Agent 会先检索、阅读相关资料，整理证据、来源和不确定性，再启动 Idea Tree。如果你提供的证据已经足够，或明确要求跳过检索，就直接使用已有材料。

启动后，研究会自行推进。聊天回复结束不代表研究结束，可以通过 Idea Tree 卡片查看进度，也可以在聊天中询问当前结果。

## 一棵树表示什么

- **研究目标**是整棵树要回答的问题。
- **方向节点**组织不同思路，并汇总该方向下学到的经验。
- **候选方案**是具体设计，包含设计说明、各项评估和综合分数。

每一轮会提出一批候选方案，完成设计与评估，再将优点、问题和待验证事项汇总到所属方向。后续轮次据此改进已有方案或探索新方向，已有结果会保留。并不是每条分支都会继续展开，也不要求所有方案达到同样深度。

## 选择研究模板和探索强度

进入**系统设置 → Idea Tree**，选择模板和探索强度，然后保存。设置对新研究生效；已经开始的研究沿用启动时的设置。

| 研究模板 | 评估关注点 |
|---|---|
| 通用科研假设探索 | 科学合理性、证据与验证准备度、可行性与风险 |
| 水处理材料设计 | 活性、稳定性、可持续性 |

探索强度有**快速、标准、深入**三档。快速适合先了解有哪些方向；标准适合一般探索；深入会展开更多分支和评估轮次，通常需要更多时间和模型用量。到达轮次或候选数量等限制，或没有可继续展开的方向时，研究会结束。

## 怎样理解评分

模型从模板规定的三个角度分别给出 1–10 分的评估，系统按模板权重计算综合分数。阅读时先看理由和证据缺口，再看分数。

高分表示方案在当前材料和评估标准下更受看好。它不等于实验成功率，也不是实测性能；例如“活性 8 分”不能换算成“污染物降解率 80%”。

## 查看与控制研究

点击 Idea Tree 卡片中的**查看研究进度**，打开树视图。选择节点可以阅读设计、评估和总结。

- **暂停**：等待已经发出的模型请求退出后暂停。在此期间可能仍有用量。
- **继续**：从已保存的进度接着运行。服务重启或调用失败后，可以先查看中断原因，解决后再继续。
- **结束**：确认后停止本次研究，保留已有结果，不能继续。需要修改目标或材料时，另开一次研究。

同一个会话同时只能运行一项 Idea Tree 研究。

## 使用边界

研究启动前可以检索和整理材料；树内探索本身不会继续上网、运行代码或做实验。需要补充新证据时，先整理材料，再发起新研究。

当前研究引擎需要可用的 Idea Tree 后端服务，以及会话中已配置密钥的 OpenAI-compatible 模型。评估依赖模型判断，多轮探索也不能替代实验验证。

如果你已有数据，希望运行分析代码、复核结果并生成报告，可以使用 [Agent Team](agent-team.md)。
