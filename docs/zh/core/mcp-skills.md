# 科研 MCP 与 Skill：既能接触数据，也知道怎样使用

科研 Agent 需要两类帮助：一类让它接触真实数据库与计算工具，另一类告诉它怎样有条理地完成工作。MCP 连接器与 Skill 分别提供这两种能力。将它们组合起来，研究才能从语言描述走向具体操作。

## MCP 把外部能力带进研究现场

通过 MCP，Agent 可以调用已配置的科研接口，例如检索论文、查询数据库记录或获取工具返回的文件。每个接口都有自己的参数和返回内容，Agent 应根据当前可用能力选择工具，而不是假设所有数据库随时在线。

连接器的价值不仅在于“搜到内容”，还在于保留结果的身份与来源。论文标题、DOI、数据库记录和可获取的正文范围，决定了下一步能够据此作出什么判断。摘要不是全文，数据库命中也不是结论已被验证。

## Skill 把做事的方法留下来

Skill 是可以读取的工作说明与配套资源。例如，文献检索技能可以指导查询设计、去重、覆盖说明和阶段结果保存；数据分析技能可以提醒先检查输入，再选择方法，最后交付可复现代码。

技能可以包含脚本和参考材料。选择技能并不等于执行其中的脚本，也不会自动安装依赖；Agent 需要在运行时读取适用内容，再使用实际工具完成操作。系统记录所用技能版本，便于回看一次任务采用了哪套方法。

## 两者一起，才能形成可复用的研究步骤

以文献调研为例：Skill 帮助规划检索与整理方式，MCP 提供实际来源，Agent 再读取证据、综合并交付报告。连接器不可用时，技能无法凭空补出数据；有大量接口但缺少清楚的方法，也可能出现重复检索和证据遗漏。

你可以从一个可用的连接器和一个适合的技能开始，再根据任务增加能力。Project / Session 的选择决定实际可用范围；配置进全局库，不代表某次受限会话一定能够调用它。

## 让经验积累，也让变更可检查

在设置中可以管理连接器，导入本地或 Git 技能包，也可以让 Agent 起草技能。Agent 生成的技能草稿需要用户审核确认后才会安装生效；有用的工作经验因此可以复用，修改过程也保留审阅机会。

外部工具输出和导入材料仍需按来源与权限使用。MCP 连接和技能选择不绕过运行时的权限控制，也不保证一次研究自动满足完整性要求。
