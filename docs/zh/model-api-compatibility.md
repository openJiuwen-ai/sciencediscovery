# 模型 API 协议兼容性

Agent、Swarm 网关、会话命名、论文视觉分析及 Evolve/IdeaTree 使用共享模型适配边界。
支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。
Gemini 原生协议和 Bedrock 原生协议不在本次范围内。

在供应商编辑器中保存端点、模型、凭据、代理及协议。协议选择和手动覆盖会持久保存，
运行时不会自动切换协议或重发探测。更改配置后需主动重新检查。

连接向导在获得同意后发送一次基础请求。供应商行的兼容性检查在明确费用同意后，
向三种协议发送最多 12 次合成请求：每种协议分别验证基础非流式响应、流式文本、
工具调用及结果回传。供应商可能收费，即使响应失败或被截断。不会发送研究任务内容。
检查结果不会更改已选协议，多种协议可以同时通过。

基础、流式、工具及 usage 结果独立展示。HTTP 200 本身不足以通过检查。
认证/授权失败、限流/余额、端点或模型不存在、供应商错误、网络和超时分别展示。
结构错误或证据不足表示无法确定；模型未调用测试工具也不等于不支持工具。
缺失或异常 usage 保持未知，不视为零用量或免费，不阻止任务完成和评测计分。

每种协议基础请求、流式请求及两轮工具请求各有 10 秒上限，总计最多约 90 秒。
基础输出最多 8 token，流式及工具每次最多 64 token，每个响应最多 64 KiB。
推理模型可能耗尽小预算，无法确定的结果不代表模型不可用。
检查不证明上游模型身份、质量或路由，也无法修复任意供应商错误。

论文图片按协议转换，Messages 使用 base64 图片；必须显式启用模型视觉能力。
Evolve/IdeaTree 保留内部非流式 Chat 接口；流式请求会明确报出限制。
工具 ID、并行结果、推理状态与签名、截断和原始错误在共享边界保留。
未知参数不会被静默丢弃。不会新增付费真实模型 PR 检查。

API 调用 `POST /api/models/:id/test` 需认证及 JSON 请求体
`{"consent":true,"compatibility":true}`；省略 compatibility 只检查已选协议的基础能力。
未同意时返回 400，不联系供应商。完整费用、限制、代理前缀和排错说明见
[英文说明](../en/model-api-compatibility.md)。

普通 Agent/Swarm 的 `requestTimeoutMs` 仍仅限制响应头等待时间；持续输出的流不会因此
被截断，明确的调用方超时或取消信号仍有效。兼容性检查保留独立的外层期限。
IdeaTree 的公开研究入口支持三种已保存协议，使用鉴权侧车和绑定模型的研究令牌。
确定的响应结构错误返回 HTTP 422，不会被当作网络故障再次付费重试；真实供应商 5xx
保留原状态、原因与既有有限重试。仅明确 `finish_reason: length` 的 Chat 空内容可保留
已报告用量与输出耗尽诊断，不能据此判定基本能力可用。
失败调用释放在途准入预留，不累加成功但未报告用量的永久预留；失败用量仍为未知，
不能声称供应商未收费。成功且用量未知的调用仍保留单独标识的保守准入预留。

研究令牌不会更改已保存协议；注册模型本身不会启动研究或自动探测。
上述上限不能证明精确 token 账单，也不是供应商费用的硬性上限。
供应商错误保留原始 HTTP 状态及 JSON 或纯文本原因；非对象或纯文本错误内容最多
保留 2,000 个字符，凭据会被脱敏，不会被误标为网络故障。
HTTP 200 的 Responses 失败响应若显式报告 `server_error`（code 或 type），仍按
供应商错误 502 处理，沿用 IdeaTree 既有的一次有限 5xx 重试。已识别的认证、限流、
无效请求错误分别保留 401/429/400 分类；未知错误保留原因并返回 422，不假定其可重试。
结构异常仍是不可重试的 422。IdeaTree 对空白或截断阶段直接报错，不发起无意义的
JSON 格式纠正；已报告用量仍入账。非空的异常 JSON 答复仍可进行既有的一次格式纠正。
