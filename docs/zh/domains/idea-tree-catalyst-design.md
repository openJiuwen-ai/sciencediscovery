# 用 Idea Tree 探索水处理催化剂

本例带你探索用于降解水中污染物的催化剂：提出不同设计，比较活性、稳定性和可持续性，再选出值得实验验证的方向。

最终得到的是候选方案及其评估依据、风险和后续验证建议。功能原理见 [Idea Tree](../core/idea-tree.md)。

## 1. 准备研究问题

先完成[快速开始](../getting-started/quick-start.md)，确认会话模型和 Idea Tree 后端可用。需要检索时，还要有可用的文献或 Web 检索工具。

本例把问题限定为“在接近中性的水中降解四环素”。你可以替换目标污染物，但要尽量说明：

- 使用条件：例如室温、接近中性；能否提供光照、投加氧化剂。
- 材料约束：例如不使用贵金属、尽量避免有毒金属溶出、便于回收。
- 已有证据：相关文献、实验记录，或已经尝试但效果不好的方案。

有材料时先上传，并请 Agent 阅读、整理。没有材料也可以开始检索；资料中没有证据支持的设想应明确标为假设。

## 2. 选择模板

打开**系统设置 → Idea Tree**，选择**水处理材料设计**模板，探索强度先选**标准**，保存。

这个模板从三个角度评估方案：活性关注预期降解能力，稳定性关注使用与循环中的性能保持，可持续性关注成本、资源和环境影响。

## 3. 发起探索

在会话中输入：

```text
/idea-tree 探索用于降解水中四环素的催化剂设计。
使用条件：室温、接近中性；可以使用可见光，若需额外氧化剂请明确说明。
约束：不使用贵金属，关注金属溶出和材料回收。

请先检索并阅读相关研究，整理已有证据、来源和不足，再启动探索。
比较不同材料组成与结构的设计思路，说明可能的作用机制、
活性与稳定性的取舍，以及下一步应做哪些验证。
不要把文献中的数据直接当作新方案的性能，也不要编造实验结果。
```

Agent 会先准备材料，再交给 Idea Tree。看到研究已启动的提示后，通过 Idea Tree 卡片中的**查看研究进度**进入树视图。

如果你已经提供足够资料，也可以补充：“只使用我提供的材料，跳过外部检索。”

## 4. 看方案怎样改进

选择一个候选节点，依次查看设计说明、三个角度的评估和总结。重点关注：

- 方案具体改了什么：材料组成、结构，还是回收方式？
- 为什么可能有效：依据来自哪份材料，哪些只是推测？
- 评估指出了什么问题：例如稳定性不足、使用条件苛刻，或缺少关键证据？
- 后续方案是否回应了这些问题，是否又引入新的代价？

例如，一个候选被指出难以回收，后续方案可能尝试固定到载体上。值得比较的是回收是否更方便，以及活性是否可能因此下降。这只是阅读思路，实际分支由本次研究产生。

需要暂时停下时点击**暂停**，准备好后点击**继续**。设置和已有材料不会随着后续聊天自动更新；要换目标或补充材料，应发起新研究。

## 5. 选出下一步要验证的方案

研究完成后，可以在聊天中提出：

```text
请读取这次 Idea Tree 的结果，比较最多三个值得继续验证的候选。
逐一说明设计差异、证据依据、主要风险，以及最先需要验证的问题。
若证据不足以推荐，请直接说明缺什么材料。
```

不要只按综合分数排序。一个得分稍低但依据更充分、验证更容易的方案，也可能更适合作为下一步。

读完结果，你应能回答：优先验证哪个设计、为什么，以及什么实验结果会让你放弃或修改它。实际实验应检查污染物去除、降解产物、材料稳定性等问题；模型评分本身不能证明处理效果。

## 换成自己的课题

将示例中的污染物、反应条件和材料约束替换为自己的需求。尽量一次回答一个清晰问题，例如“如何兼顾降解活性与可回收性”，比“设计最好的催化剂”更容易比较结果。
