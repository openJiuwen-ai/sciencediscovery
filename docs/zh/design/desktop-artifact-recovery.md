# 桌面对话产物恢复与展开

版本：1 — 2026-11-23。基于 #1257 的增量，关联 #1202、PR #1228。

保留 main 的 `TurnArtifactStrip` 卡片、`turnArtifactsByRun` 分组和精确版本预览。
本设计替代 #1228 早期提交中的全宽列表设计，不引入第二套分组或渲染路径。

## 需求

- **AR-1：持久归属。** 独立于事件回放保留终态 SessionRun，沿用会话切换、请求代次
  和有界缓存保护。产物版本必须属于当前会话，并通过现有轮次、子代理归属解析。
  未知归属或循环关系不猜测。
- **AR-2：读取恢复。** 回放没有子代理关系时读取已有目录接口。同一客户端、会话和
  来源集合复用成功结果；失败后在下一次产物刷新重试，包括同一子代理产生新版本的情况。
  切换会话或客户端后，旧请求不得写入当前视图。
- **AR-3：唯一锚点。** 优先使用回放中的回复，否则使用持久回复。两者均不存在时，
  在该轮提问之后的运行状态下显示产物。没有有效产物的轮次不合成空白记录。
  活跃或等待审批的运行即使事件连接结束也不显示产物条；保留取消、失败和按轮用量展示。
- **AR-4：就地展开。** 保留现有排序和重要类型优先的默认选择，最多显示五个文件卡片。
  “更多”展开同一产物条中的全部文件，包括中间文件；支持收起和打开产物面板。
  展开和收起按钮用 `aria-controls` 关联列表，提供 `aria-expanded`，切换后把键盘焦点
  交给对应的另一按钮。点击卡片仍打开该轮保存的精确版本。
- **AR-5：验证证据。** 中英文实际界面覆盖日志裁剪或读取失败、无回复的完成、失败和
  取消状态、同一子代理的目录失败恢复、实时转回放去重、会话切换、历史 v1/v2、展开收起
  和窄窗口长文件名。记录不可变的验证提交，并更新 PR 截图。

## 验收

每个有产物的终态运行只显示一个产物条。目录临时失败后无需重新打开会话即可恢复。
历史卡片分别打开 v1/v2 的真实内容。测试同时覆盖跨会话隔离、过期异步响应和成功缓存复用。
沿用现有分组、排序、面板交互测试。

运行桌面类型检查、单元测试、浏览器流程和仓库要求的 WSL 验证，分别记录实际通过数、
策略跳过和环境阻塞。PR 明确归属 #1257 已完成的功能，暂用 `Refs #1202`，避免提前关闭需求。
