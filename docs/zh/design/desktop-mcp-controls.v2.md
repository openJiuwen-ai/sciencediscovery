# 桌面 MCP 控件 v2：行操作菜单

日期：2026-11-25。根据用户要求，在 [v1](desktop-mcp-controls.v1.md) 的基础上将行操作风格统一为技能页菜单。v1 的添加入口、服务启停及默认使用要求继续有效。

| 编号 | 行为 |
| --- | --- |
| MCP-CTRL-06 | 将自定义 MCP 行内的工具、测试、编辑、删除链接收进与技能页一致的小箭头图标菜单，复用菜单控件、悬浮样式及带分隔线的红色删除项。保留技能原有导出、编辑、删除权限和行为。 |
| MCP-CTRL-07 | 标注清楚的默认使用复选框和服务启用开关保留在菜单外。OAuth 授权、取消授权、打开授权页兜底及清除授权在适用时继续从菜单可达。内置来源保留其支持的默认使用操作。 |
| MCP-CTRL-08 | 鼠标悬浮、点击、触摸和键盘均可访问操作。Escape 只关闭菜单并将焦点返回触发按钮。忙碌及不可用操作保持禁用；菜单根据空间向上或向下展开，必要时内部滚动。保留连接测试、编辑、确认删除、失败恢复及取消未保存修改。 |

验收：桌面单元测试保护技能和 MCP 的操作可用性；浏览器旅程覆盖菜单、两处启用控件、导入、编辑、连接测试及取消/确认删除。检查常规和较小桌面窗口中的中英文实际截图。复用隔离依赖，所有测试证据与用户数据分离。

MCP-CTRL-08 键盘验收：点击触发按钮展开菜单后，焦点可能仍停留在按钮上。此时向上键必须进入最后一个可用菜单项，向下键进入第一个；之后继续按键时在可用项之间循环。

MCP-CTRL-06/07 视觉验收：授权进行中的打开授权页链接使用与按钮菜单项一致的普通文字和悬浮样式，不显示链接下划线。中英文截图均覆盖授权进行中状态，同时保留外部链接语义。

最新 MCP 布局和 PR 范围见 [v3](desktop-mcp-controls.v3.md)。
