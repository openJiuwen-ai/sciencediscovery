# 桌面 MCP 添加与启用控件 v1

与技能页统一行操作菜单的补充要求见 [v2](desktop-mcp-controls.v2.md)。

日期：2026-11-25。仅调整 main 现有桌面 MCP 设置页，独立于私仓里的卡片、抽屉整体改版。复用现有新增、编辑、JSON 导入弹窗及 API。

| 编号 | 约定 |
| --- | --- |
| MCP-CTRL-01 | 页面标题右侧放置与技能页一致的黑色“添加服务器”胶囊按钮，下拉提供“手动填写 / 导入 JSON”。空列表同样可用，保留键盘、焦点、外部点击和 Escape 行为。 |
| MCP-CTRL-02 | 手动填写打开现有新增表单；导入打开现有 JSON 弹窗，在其中提供粘贴和上传文件。保留预览、大小与条目数限制、取消及逐项导入结果，不合入私仓改版的预填草稿流程。 |
| MCP-CTRL-03 | 自定义服务器列表开关与编辑表单“启用服务”勾选均控制已保存的 enabled 字段。保存成功后刷新两处状态；编辑未保存时仍是草稿。写入失败保留原状态并显示错误。 |
| MCP-CTRL-04 | 会话默认选用、服务启用和连接状态继续独立。内置与自定义来源均以单独、明确标注的“默认使用”复选框控制会话默认选用；批量操作仅改变默认选用。启用不自动选为默认，默认选用不偷偷启用服务。内置来源不增加不存在的服务启停操作。 |
| MCP-CTRL-05 | 列表启停须保留已存凭据、OAuth 参数与未改动的 STDIO 原参数数组。端到端覆盖列表与编辑双向修改、保存后刷新、拒绝写入、默认使用独立性、两种添加入口、键盘、中英文及小窗口。 |

连接状态仍为最近实际探测或工具发现结果，不是心跳状态。不修改后端、协议、依赖和门禁策略。
MCP-CTRL-05 的小窗口布局：操作区在空间不足时换到服务器信息下方，名称、状态标签和地址应保持可读，不能被控件挤压遮挡。
