## 需求与验收

- **SPUI-01 列表：** 三/二/一列响应式卡片，首字彩色图标、来源与能力标签，
  全部/我的/官方分类及数量，按名称和描述搜索，一键启停、黑色新增按钮。
  点击卡片进入详情，开关和操作按钮不触发详情。固定审查角色单独标识，不参与批量操作。
- **SPUI-02 操作：** 竖向三点菜单，内置和自定义角色均有「去试试」，停用时不可开启
  新会话。只有自定义角色可删除；编辑入口移至详情头部。内置不可编辑、删除。
  删除须确认，失败显示真实原因，从详情删除成功后返回刷新后的列表。
- **SPUI-03 编辑：** 新增/编辑为独立子页，带返回及吸底的取消/保存。包括名称、描述、
  指令、运行环境、能力模式、分别折叠的技能/MCP 配置和可选提示示例。保留已有
  80/500/20,000 字符上限，不用稿中的 1,000 指令计数截断已有合法内容。
  保存失败保留完整草稿并允许重试。
- **SPUI-04 能力抽屉：** 技能和 MCP 分别打开侧栏，支持来源分类、搜索、卡片复选、
  已选数量、取消/确定；只有确定才更新父草稿。缺失的已选 ID 明确显示并可移除。
  内置技能加载失败时标记为不可用。技能抽屉不提供此类技能，确认时会清除已保存的失败项。
  现有 API 的空能力列表代表继承，因此指定能力模式至少选择一项，避免空选悄悄变成全部能力。
- **SPUI-05 详情与体验：** 详情完整展示指令、运行环境、能力名称与提示示例。
  去试试创建绑定该已启用专家的新收件箱会话，点击示例只预填一次输入框。
  如果专家在选择后被停用，创建会话 API 会拒绝新绑定。
  两者都不自动提交 Run 或调用模型，也不改变既有会话及其草稿的绑定。
- **SPUI-06 提示示例：** 专家及新增/更新接口增加可选持久化字段
  `promptExamples: string[]`，最多十项，每项非空且不超过 1,000 字符。
  旧记录缺失时视为空，编辑保留；内置仍只读。示例只用于 UI，不自动拼入系统指令。
- **SPUI-07 兼容：** 保留启停持久化、批量部分失败刷新、缺失技能显式修复和停用会话
  绑定的真实显示。新增样式限定在专家界面，技能/MCP 管理页保持现状。
