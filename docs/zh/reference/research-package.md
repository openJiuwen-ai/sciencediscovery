# ScienceDiscovery 科研证据包

ScienceDiscovery 使用 `.sdresearch` 作为科研证据包的文件后缀。证据包由 `research-package` 插件提供，插件在构建时安装并由宿主显式启用；包本身只是数据格式，不是可执行插件。

## 首版格式

首版格式标识为 `sciencediscovery-research-package`，schema version 为 `1`，默认 `packageKind` 为 `evidence`。归档采用 tar+gzip，包含：

- `manifest.json`：格式版本、来源项目/会话、生产者版本、包类型、文件清单和遗漏说明；
- `records.json`：结构化科研记录，例如主张、证据引用和运行元数据；
- `README.md`：面向人的包说明；
- `objects/<sha256>`：按 SHA-256 内容寻址的证据对象、日志或产物。

导出时会为每个记录和对象写入大小与 SHA-256 校验值。导入和 inspect 会先校验归档路径、文件类型、重复项、大小限制、清单完整性和所有校验值，再解析记录。导入接口返回只读结果；它不会运行对象、脚本、命令或包内的任何代码。

Web 可从每个会话的“更多会话操作 → 导出”进入会话导出或证据包导出。会话导出支持 Markdown 和浏览器打印为 PDF，并可选择整段对话或指定 Prompt 及其后续回复。证据包支持“必要导出”和“完整导出”，也可以选择包含的工作区文件。

两种级别均保留所选会话的全部可见消息，默认内容范围如下：

| 内容 | 必要导出（默认） | 完整导出 |
| --- | --- | --- |
| 产物 | 当前版本及递归引用的输入版本 | 所选范围内所有已有版本 |
| 工作区文件 | 上传输入、产物源文件和与保留执行有关的文件 | 所选会话全部已有文件 |
| 执行与溯源 | 当前结果、文件及验证直接关联的执行代码和日志原文，以及最近成功执行 | 全部已有任务执行、代码和日志 |
| 验证 | 保留版本的最近完成审核及相关结论 | 全部已有验证和审计记录 |
| 科学记忆 | 当前结果、相关执行及其溯源祖先节点与关系 | 所选范围内原始图谱，包括界面隐藏的节点与关系 |
| 轨迹 | 最近模型输入、最终输出、相关工具摘要（过长摘要明确标记截断） | 默认轨迹摘要；勾选“包含完整轨迹”后保存全部已保存输入、思考分片、工具详情及原始运行事件流 |
| 文件修订 | 当前修订的归属与关联 | 全部已有修订元数据 |

必要导出按溯源选择文件，不会仅因 `.py`、`.json` 等扩展名而排除文件。可以在“自定义内容”中调整文件勾选，包括全部取消；取消文件不移除独立登记的产物内容。切换级别会恢复该级别的默认勾选。预览显示实际选中数量、未压缩估算大小及省略说明，实际下载大小以压缩后的证据包为准；预览不生成压缩包。没有可省略历史的简单会话，两种导出的内容可能接近；不会人为增加数据制造体积差异。

会话打开后，系统在后台预计算必要导出、完整导出及包含完整轨迹的完整导出大小，无需先打开导出对话框。后台每 3 秒检查研究内容版本；内容不变时复用预览，不再按 1 分钟过期。回复、文件、执行记录或通过本 API 写入的科学记忆变化后自动重算。预计算完成后打开导出即可显示两种级别的大小；内容刚更新或首次计算尚未完成时显示计算状态。切换级别或完整轨迹选项复用已有结果，相同请求合并并串行计算；自定义文件选择按内容版本及实际勾选组合缓存，连续勾选合并计算。预览使用文件大小和已有内容标识，避免为计算大小读取全部工作区与产物字节，不生成压缩包。实际下载始终重新读取当前内容。

完整导出的结构化记录按小片段编码为 JSON 字节，大记录导入时按字节分段解析，避免将整个会话拼成一个超长字符串。归档仍采用首版格式，轨迹、模型输入、思考和日志不会因此截断；导入后的记录保存及研究副本完整性校验也避免生成聚合字符串。该处理不取消宿主内存和归档容量限制。

产物的输入依赖若属于其他会话，必要导出会同时带上其来源会话，以保持依赖可恢复；不会自动包含项目中其他无关会话。导入会为目标项目重新映射会话、执行、文件和产物标识，恢复关联并持久保存；跨会话产物仍归属于来源会话，不能通过会话 A 的文件列表进入会话 B。

新包的 manifest、records 和导入/导出回执保存 `exportProfile`，记录导出级别、包含与省略数量以及历史完整度。必要包允许创建研究副本，但仅复制包内已有内容，无法补回省略的历史；内部快照捕获不会将其重新标成完整包。来源经过精简时，再次选择完整导出也会保留历史受限说明。旧包缺少此字段时继续兼容，界面提示以实际内容为准。

导入后可从文件溯源查看来源、修订和关联产物，从产物溯源查看代码、输出和输入证据，在任务执行记录中查看已保存日志，并通过“在科学记忆中查看此产物”打开恢复的图谱。历史执行不会连接原来的 Runner 或自动重跑。图谱服务不可用时，导入保留只读快照并记录科学记忆恢复失败，同时禁用继续研究；恢复服务后需重新导入。

完整导出保存轨迹的完整只读详情，包括每次调用的固定模型输入、思考分片、最终返回、工具参数和结果，以及可用的 Agent 状态。必要导出则保存上表所述摘要，并明确提示限制。导入及创建研究副本只重新映射导航标识，保持包中正文原样，不用当前上下文替代历史输入。新研究会话将导入轨迹与后续执行轨迹一起展示。旧包若包含原始上下文对象，查看器兼容原会话的身份关联；旧包导出时已遗漏的轨迹日志或正文无法凭空恢复，需要从原始会话重新完整导出。

## 只读快照与继续研究

新导入会话会保存为“导入证据快照 · 只读”。可以查看消息、文件、产物版本、溯源、历史任务日志及科学记忆，也可以下载、导出和归档。消息发送、上传、执行和研究设置变更由后端拒绝；解除归档不会解除证据锁。已有的旧导入会话不会自动锁定。

导入完成对话框和会话输入区均提供“创建新会话继续研究”，输入区同时显示快照只读状态。系统复制同次导入的全部关联会话，并在恢复后核对消息、文件哈希、产物版本与依赖、文件修订、执行日志、事件流及原始科学记忆关系。新会话使用独立工作区和重新映射的记录标识，保留原始内容与历史时间；当前模型、运行器和权限使用本机配置，不重放历史任务或授权。新研究会话首次打开时，来源提示显示 10 秒后自动消失，切换或刷新不会重新开始计时。

工作区中的 Python、JSON 等普通文本文件无需登记为产物，点击即可在对话框中查看原文。文本预览最多读取前 256 KiB，超出部分明确提示截断；PNG、JPEG、GIF、WebP 等图片使用完整文件直接预览。通过右上角下载图标可获取完整原始字节，并保留原文件名、大小写及扩展名。空文件、其他二进制或暂不支持的编码会显示相应提示；Markdown 和 CSV 继续使用专用查看器。只读快照允许预览和下载。

复制期间显示“正在复制研究记录…”，并通过应用内的后台任务提示持续跟踪。切换会话或关闭导入对话框不会取消服务端复制；刷新页面后可恢复任务跟踪。一直停留在原会话时，完成后自动打开新会话；已经切走时保留当前会话，通过任务提示的“打开会话”进入副本。只有完成核对的副本才会开放研究；网络重试沿用相同请求标识，避免重复复制。复制失败不会开放半成品会话，并按该操作范围清理，图谱服务不可用时保留隔离状态供重启后再次清理。服务端重启中断的复制会提示失败并允许重试，不承诺跨服务重启续传。包本来缺失的内容及其说明会保留；导入恢复发生额外错误时，不开放完整继续研究入口。

可在本地依次验证：导入后刷新仍只读；点击继续研究后检查消息、产物溯源、任务日志和科学记忆；修改新会话文件后确认原快照内容不变。此流程仍需运行中的 API、Runner 和科学记忆服务，静态编译不能代替实际验证。

## 聊天分支

用户消息提供“复制消息”，普通模型回复沿用已有复制操作；通过执行轨迹回放的历史回复也提供复制按钮，复制原始回复正文。已完成的正式回复后，可通过更多操作中的“分支到新聊天”创建独立、可继续研究的会话。原会话需要没有执行中的任务；导入的只读快照不支持直接分叉，需先“创建新会话继续研究”，再从可写的研究会话分叉。

分支保留截至所选回复的消息和可核实归属的产物版本、执行记录、轨迹及文件修订，不包含其后的消息或证据。历史文件仅在原始字节仍可取得时恢复，不用当前文件替代旧版本；科学记忆仅继承能够按版本、执行和文件内容核实的节点及关系。缺少历史载荷或归属不明的记录会在分支边界的“继承的研究记录及范围说明”中列出，来源包已省略的内容无法补回。

分支边界显示“从聊天中继续”，点击后返回直接来源会话并定位原回复；刷新后仍保留此入口。分支可以再次分叉，各自指向直接来源，不会修改原会话。来源已删除时保留分支内容并提示无法返回。

接口为 `POST /api/sessions/:sessionId/conversation-branches`，请求体包含 `messageId` 和 `requestId`。相同请求标识返回同一复制操作，可通过现有 `GET /api/sessions/:sessionId/research-continuations/:operationId` 查询进度，避免连接中断重试时重复创建会话。

## 复现限制

校验通过表示包内字节完整、格式正确，并不表示科研结论已经被复现。要得到可复现结论，还需要在目标环境中具备相同或兼容的代码、数据、模型、依赖、硬件和随机性控制条件。`verified-reproduction` 与 `combined` 类型已预留，后续可以在不改变后缀的情况下扩展清单和复现元数据。

## 宿主接入

`research-package` 插件的 provider 已接入 API 和 Web 宿主：

- `GET /api/projects/:projectId/research-package?sessionId=...` 导出项目或指定会话；
- `POST /api/projects/:projectId/research-package/inspect` 只校验并返回包摘要；
- `POST /api/projects/:projectId/research-package/import?sessionId=...` 导入并保存包。
- `POST /api/sessions/:sessionId/research-continuations` 使用 `requestId` 创建或查询幂等复制操作；
- `GET /api/sessions/:sessionId/research-continuations/:operationId` 查询状态和新会话入口。

导出会自动收集项目/会话元数据、会话消息、运行记录、Artifact 版本和工作区文件；大对象以 `objects/<sha256>` 保存，记录中保留对应引用。导入会将可映射的记录写入目标项目数据目录，并保留原始包供审计：

```text
projects/<projectId>/research-packages/<packageChecksum>/<operationId>/
  manifest.json
  records.json
  README.md
  objects/<sha256>
  receipt.json
  snapshot.sdresearch
```

旧版本包若没有工作区当前文件、科学记忆或历史执行记录，系统无法从哈希或元数据重建这些内容，会在 receipt 中保留相应遗漏说明；需要使用更新后的版本从原始项目重新导出。包中的工作区修订目前保存完整修订元数据及当前文件字节；旧修订字节与独立 Notebook 执行历史尚未持久化，因此不承诺恢复它们。运行中的任务导入后会标记为已取消，不会自动重跑；跨环境获得相同结论还需要兼容的软件、数据、模型、硬件与随机性设置。
