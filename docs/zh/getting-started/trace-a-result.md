# 追溯一个结果

结果的价值取决于你能否核查它。本课从[分析一份数据](analyze-a-dataset.md)中的图和报告出发，追溯产生它们的代码、环境和输入，根据 Reviewer 的发现得到第二个版本，并撤销你授予过的权限。

- **用时：**约 15 分钟，包括一次较短的运行。
- **你需要：**[分析一份数据](analyze-a-dataset.md)中的 Session，其产物中有 `growth-report.md` 和 `treatment-boxplot.png`。
- **Skill 与连接器：**不需要。
- **完成后得到：**`growth-report.md` 的第 2 版及其与第 1 版的对比，并撤销那一课中的代码执行授权。

[评审与溯源机制](../developer-docs/review-provenance.md)说明了记录哪些内容以及原因。

## 1. 查看图的溯源

打开该 Session，在 **产物** 列表中打开 `treatment-boxplot.png`，从 **预览** 切换到 **溯源**。你应该看到：

- 产生这张图的命令，通常是运行分析脚本，并可 **下载脚本**；
- **执行日志**，包含退出码和脚本打印的输出；
- **工作目录**，以及默认折叠的 **进程环境**；
- **受管软件包环境**，列出这次运行使用的确切软件包版本，例如 pandas、SciPy 和 Matplotlib。

这些是实际运行的记录，不是模型写出的描述。

## 2. 查看工作区文件的来源

在 **工作区** 面板的 **文件** 下，先点击 `plant-growth.csv` 旁的信息图标，再点击 `treatment-boxplot.png` 旁的信息图标。前者的来源是 **用户上传**；后者显示写出它的工具和执行、**关联产物** 以及 **修订历史**。

## 3. 阅读 Reviewer 的发现

新安装默认开启 Reviewer 和自动审查。`growth-report.md` 登记约一分钟后，对话中出现了一张 Reviewer 卡片。打开它。快速级别的常见发现会指出报告中没有关联到记录证据的数字，并建议补上关联。

这些发现不会修改产物。它们是给你和 Agent 的提示；Reviewer 也可能出错。要关闭某个 Session 的自动评审，使用消息框下方审批模式旁边的 **自动审查**。

## 4. 请求修订

发送：

```text
Reviewer 卡片列出了 growth-report.md 中没有关联到记录证据的数字。请添加一个简短的“数字来源”小节，为每个表格和检验写明产生它的脚本和结果文件，并把被指出的数值关联到这些记录。不要重新运行分析，也不要改动任何数字。保存文件，并再次登记 growth-report.md，使它成为同一产物的第 2 版。
```

你应该看到：Agent 读取报告和之前的记录，编辑文件，然后再次登记。产物现在显示版本选择，例如 **第 2 版 / 共 2 版**；对话中会提到新版本。之后可能会有新的自动评审，它仍可能给出发现。

## 5. 对比版本

打开 `growth-report.md`，选择第 2 版，并在 **对比对象** 中选择第 1 版。差异中会显示新增的小节和添加了关联的行。抽查几个数值：两个版本中应该相同，因为提示要求的是添加关联，而不是重新计算。两个版本都会保留；打开第 1 版仍能看到原始文本及其自身的溯源。

## 6. 撤销你授予的权限

在数据分析课中，你为代码执行选择了 **允许同类操作**，这留下了一项长期授权。打开 **系统设置 → 权限**。在 **长期权限授权** 下，每项授权都显示动作（例如 **运行本地代码**）和它覆盖的资源（例如 `workspace-code`）。对代码执行授权点击 **撤销**。每个选择过 **允许同类操作** 的 Session 都有自己的授权，前面课程中的每个连接器工具也各有一项；撤销你不再需要的授权。撤销会把授权从列表中移除；已经运行过的执行仍保留其记录和溯源。

## 7. 确认结果

- [ ] 图的 **溯源** 标签页显示了命令、退出码和运行时使用的软件包版本。
- [ ] `plant-growth.csv` 的来源是 **用户上传**。
- [ ] `growth-report.md` 有两个版本，**对比对象** 能显示差异。
- [ ] **长期权限授权** 中不再列出你撤销的授权。
