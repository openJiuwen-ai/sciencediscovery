# Contributing to ScienceDiscovery

This branch distributes ScienceDiscovery as a preprovided binary and does not support building from source. The documentation here therefore covers only how to run the preprovided executable; it does not provide source-level development or build steps.

To run the product, see the [README](README.md) and the [deployment guide](docs/en/how-to/deployment.md) (中文部署指南见 [docs/zh/how-to/deployment.md](docs/zh/how-to/deployment.md)). The full documentation set is under [docs/](docs/).

Source-level changes should be made from a checkout that contains the complete source tree, not this release branch.
