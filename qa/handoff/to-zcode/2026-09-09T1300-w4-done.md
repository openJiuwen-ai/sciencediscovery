## 交付范围

- **在线写时消解**（开关 `SCIENCE_AGENT_KE_ENTITY_RESOLUTION` env 或 ke_settings `entity_resolution_mode`：`off`（默认，逐字节旧行为）/`shadow`（只审计）/`on`（真合并））：L0 精确 → L1 别名 → L2 文档内 Schwartz–Hearst 缩写对 → L3 embedding（≥0.95 + 同类型 + 非 core 才直合并）→ L3.5 短名熵门（≤4 字符走 trgm 召回优先）→ L4 预算化 LLM 裁决（每文档 8 次弹性预算，遍历灰区全部邻居）。**每层 fail-open 到 new**；整个 decide+attach 块异常时回退普通 upsert，抽取 job 不会被打死。
- **离线批量**（`ke_entity_resolution` job，POST `/kbs/:id/resolution`）：类型 blocking → 双通道召回（trigram ∪ embedding cosine）→ 连通分量（超 25 最弱边裁剪）→ 每分量一次 LLM-CER 簇裁决 → 物理合并，≥10% 合并率迭代收敛。**已裁决对（含拒绝）缓存于 ke_entity_merges，杀/续跑不重判**；shadow 预览不进缓存（shadow→on 工作流可用）。
- **物理合并/回滚**：ke_entity_merges 全量快照（双方实体行+被吸收边+文档明细）；边重定向碰撞折叠、自环丢弃、ke_entity_docs 去重文档重计（GREATEST 不 naive-sum 不降）；unmerge 尽力回滚（POST `/merges/:id/unmerge`）；在线 attach 审计行用合成 id，不可 unmerge。
- **社区**：确定性多层 Louvain 直搬；GET `/kbs/:id/roots` 指纹缓存（实体/边计数+support 总和+最新边时间）+ SWR 后台重算（per-KB 去重 + 60s 限速）+ 一次批量 LLM 命名（无模型时回退代表实体名）；community_id 持久化到实体行。
- **前端渐进下钻**：社区气泡（大小∝√成员数）→ 点击看成员子图 → 点击实体看证据；面包屑 Communities / Full graph / 社区名；侧栏新增 "Resolve duplicate entities" 按钮。
- **评测**：`node scripts/ke-resolution-eval.mjs [--set pairs.sample|pairs.realworld] [--trgm]`（in-process 零服务）。确定性基线 pairs.sample：**P=1.000 R=0.583 similar 14/14 unrelated 8/8**（已钉进 packages 回归测试）；gate NOT-YET 是诚实的——R≥0.60 需要 L3/L4（真实模型）。realworld 集确定性 R=0（全在 L3/L4 盲区），符合 DA 记录。
